私隱政策

最後更新：2026 年 8 月 19 日

本私隱政策說明 TrackpadGesture 網站及 macOS 應用程式如何處理資料。我們只會按提供及支援產品所需的程度處理資料，並不會出售你的個人資料。

1. 我們可能收集的資料

當你下載或瀏覽網站時，GitHub Pages 或瀏覽器可能自動處理基本技術資料，例如瀏覽器類型、裝置類型及一般請求資訊。當你購買或啟用授權時，付款平台可能向我們提供訂單識別碼、付款狀態、產品及授權所需的資料；完整付款卡資料由付款平台處理，我們不會儲存完整卡號。

當你聯絡支援時，你主動提供的姓名、電郵、裝置及錯誤資料可能會被處理，以便回覆及排查問題。請不要在支援訊息中提交密碼、完整付款卡資料或其他不必要的敏感資料。

2. 應用程式權限及本機資料

TrackpadGesture 需要 macOS 的輸入監控及輔助使用權限，才能偵測指定手勢及執行複製／貼上功能。授權狀態及試用狀態可能以本機資料及 Keychain 項目保存。應用程式不會以這些權限讀取與產品功能無關的內容，也不會把剪貼簿內容上傳到我們的伺服器。

3. 使用資料的目的

我們使用資料來提供下載、處理付款、啟用及驗證 license key、提供客戶支援、偵測濫用及改善產品。除非法律要求、付款平台處理需要或你主動要求，我們不會把資料用於無關的行銷目的。

4. 第三方服務

網站寄存及下載可能由 GitHub Pages 及 GitHub 提供；付款及部分稅務處理由你使用的付款平台提供；授權驗證服務可能處理 license key、訂單及裝置識別資料。這些第三方會按自己的政策處理資料，使用付款或授權功能即表示你亦可能受其條款約束。

5. 保存及安全

我們只在提供產品、處理退款、解決爭議及履行法律責任所需期間保存資料。雖然我們採取合理安全措施，但任何網絡傳輸或儲存方式都不能保證絕對安全。

6. 你的選擇及聯絡

你可以透過 GitHub Issues 聯絡我們，查詢、更正或要求刪除與你有關的資料；我們可能需要先確認你的身份。法律或付款紀錄保存要求可能限制刪除範圍。
