# Trackpad Gesture

A lightweight macOS menu bar app that lets you **Copy** and **Paste** using simple two-finger gestures on the trackpad.

## Features

- Swipe **up** on the far right of the trackpad → Paste
- Swipe **down** on the far right of the trackpad → Copy
- 60-day free trial
- Online license activation via Lemon Squeezy
- Launch at Login support
- Offline grace period (7 days)

## Requirements

- macOS 13.0 or later
- Input Monitoring permission
- Accessibility permission

## How to Use

1. Move two fingers to the **far right** side of the trackpad
2. Swipe **up** → Paste
3. Swipe **down** → Copy

## Installation

1. Download the latest release
2. Open the app
3. Grant **Input Monitoring** and **Accessibility** permissions when prompted
   (or open them manually from the main window)
