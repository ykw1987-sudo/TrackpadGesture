主要功能與特色

⚡️

觸控板右側極速觸發

將雙指移動至觸控板最右側（>86% 區域），直覺輕劃即可完成剪貼簿操作，毫不干擾日常滑動。

📋

直覺手勢：複製與貼上

雙指邊緣向上滑動即時「貼上」，向下滑動即時「複製」。徹底告別 ⌘+C / ⌘+V 繁瑣組合鍵。

🔔

原生 HUD 與觸覺回饋

觸發時提供 Mac 系統級觸覺震動，並在游標旁顯示清晰精美的微型 HUD 浮動圖示。

🛡️

防誤觸與智能凍結

內建 Multitouch 私有底層框架優化，觸發手勢時自動壓制網頁滾動，離開左側 zone 瞬間即時解凍。

如何使用 TrackpadGesture

將雙指移動至觸控板最右側區域並滑動：

👉 👆
向上輕劃 執行貼上 (Paste)
👉 👇
向下輕劃 執行複製 (Copy)

系統需求與安全性

  • 作業系統 macOS 13.0 (Ventura) 或更新版本
  • 晶片架構 原生支援 Apple Silicon (M1/M2/M3/M4) 及 Intel 處理器
  • 安全公證 已使用 Developer ID 簽名並通過 Apple 公證
  • 系統權限 需開啟「輸入監控」與「輔助使用」
